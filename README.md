# HTML-Games

ブラウザだけで遊べる、1ファイル完結のHTMLゲーム集です。インストールやビルドは不要で、HTMLファイルをブラウザで開くだけで動きます。

**遊ぶ（GitHub Pages）**: https://masahiromiyazaki.github.io/HTML-Games/

| ゲーム | ファイル | 説明 |
|---|---|---|
| リバーシ | [reversi.html](reversi.html) | CPU対戦 / 2人プレイ。CPUは4段階 |
| 将棋 | [shogi.html](shogi.html) | CPU対戦 / 2人プレイ。二歩・打ち歩詰め・千日手・入玉宣言に対応 |
| 軍人将棋 | [gunjin-shogi.html](gunjin-shogi.html) | 一人用（CPU対戦）。相手の駒は伏せられ、CPUも正体を知らない状態で指す |
| チェス | [chess.html](chess.html) | CPU対戦 / 2人プレイ。キャスリング・アンパッサン・プロモーションに対応 |

## リバーシ

### 操作方法

| 入力 | 操作 |
|---|---|
| タッチ / マウス | 打ちたいマスをタップ（クリック） |
| キーボード | `←↑→↓` / `WASD` でカーソル移動、`Enter` / `Space` で確定、`R` でリセット |
| ゲームパッド | 十字キー / 左スティックで移動、Aボタンで確定、Startでリセット |

置ける場所には薄い点が表示されます。置けない場所をタップしても何も起きません。

### CPUの強さ

| 段階 | 概要 |
|---|---|
| ノーマル | 位置の重み表に、ひっくり返す枚数を足して選ぶ（1手読み） |
| ハイレベル | アルファベータ法で5手先まで読む。残り9マス以下は終局まで読み切る |
| ヘルモード | 反復深化 + 置換表。最大約1.5秒、中盤10手先まで。残り14マス以下は読み切りを目指す |
| ナイトメア | 同上で最大約5秒、中盤20手先まで。残り20マス以下は読み切りを目指す |

ヘルモード以上は Web Worker で思考するため、考えている間も画面は固まりません。Worker が使えない環境では通常の処理に自動で切り替わります。
思考時間・先読み深さは `reversi.html` 内の `LEVELS`（ヘルモード / ナイトメア）、`SEARCH_DEPTH` / `EXACT_EMPTIES`（ハイレベル）で調整できます。

## 将棋

あなたが先手、CPUが後手です（2人プレイも選べます）。

### 操作方法

| 入力 | 操作 |
|---|---|
| タッチ / マウス | 動かす駒（または持ち駒）をタップし、続けて移動先のマスをタップ。成れる手を指すと「成る／成らない」ボタンが出ます |
| キーボード | `←↑→↓` / `WASD` でカーソル移動、`Enter` / `Space` で確定、`Esc` で取消、`Q` / `E` で持ち駒の選択、`R` でリセット |
| ゲームパッド | 十字キー / 左スティックで移動、Aボタンで確定、Bボタンで取消、LB / RBで持ち駒の選択、Startでリセット、Yボタンで入玉宣言 |

### ルール対応

- 王手の放置・二歩・打ち歩詰めは指せません。詰みは自動で判定します。
- 千日手: 同一局面が4回で引き分け。連続王手の千日手は、王手をかけ続けた側の負けです。
- 入玉宣言: 条件（点数が先手28点／後手27点以上など）を満たすとボタンが出ます。

### CPUの仕組み

駒の価値を中心にした評価（位置の評価は歩1枚分を超えない小さな重み）で、根の手のあと2手読み＋静止探索（取り合いと王手の延長）を行います。最善手と同等の手は乱数で選ぶので、毎回同じ展開にはなりません。1手の思考時間は最大約2.5秒で、超えた場合はそこまでの最善手で指します。
読みの深さは `shogi.html` 内の `DEPTH`、思考時間の上限は `TIME_LIMIT` で調整できます。

## 軍人将棋

一人用（CPU対戦）です。盤は8×9、駒は各31枚で、相手の駒は伏せられています。CPUも人間の駒の正体は知らず、動きと勝敗から推測して指します。ルールは製品や地域で差があるため、一般的なものを参考にこのゲーム用に決めたものです（司令部・突入口・浮島はありません）。

### 遊び方

1. 最初に自分の駒（下側）を2つタップして入れ替え、「開始」を押します（「配置シャッフル」で配置をやり直せます）。
2. 駒をタップし、続けて行き先をタップして動かします。相手の駒がある場所を選ぶと攻撃です。
3. 相手の駒をタップすると、これまでの動きと勝敗から絞り込んだ「正体の可能性」が表示されます。
4. 勝利条件は、敵の軍旗を取ること、または相手が動かせる駒をすべて失うことです。決着後は全駒が公開されます。

### 駒の動き

| 駒 | 動き |
|---|---|
| 大将・中将・少将・大佐・中佐・少佐・大尉・中尉・少尉・スパイ | 縦横に1マス |
| 騎兵・タンク | 縦に2マスまで、横に1マスまで |
| 工兵 | 縦横に何マスでも（駒は飛び越せない） |
| 飛行機 | 縦横に何マスでも（駒を飛び越せる） |
| 地雷・軍旗 | 動けない |

### 勝敗

- 強さの順は 大将＞中将＞飛行機＞少将＞タンク＞大佐＞中佐＞少佐＞大尉＞中尉＞少尉＞騎兵＞工兵＞スパイ。同格は相打ちで、両方とも取り除かれます。
- スパイは大将に勝ちます（攻撃側・守備側のどちらでも）。
- 地雷を攻撃した駒は、工兵と飛行機以外は負けます（地雷はその場に残ります）。工兵と飛行機は地雷を除去して進めます。
- 敵の軍旗を取った側の勝ちです。
- 400手に達すると引き分けです。

## チェス

あなたが白（下側）、CPUが黒です（2人プレイも選べます）。

- 駒をタップし、続けて行き先をタップします。動かせるマスが表示されます。
- キャスリング、アンパッサン、プロモーション（成る駒を選択）に対応しています。
- チェックメイトで決着し、ステイルメイト・50手ルール・駒不足（キングのみ、またはキング＋ビショップ／ナイト1枚）は引き分けです。三回同形の引き分けには対応していません。
- CPUは3手先まで読みます（強さの段階は1つ）。読みの深さは `chess.html` 内の `DEPTH` で調整できます（大きくすると思考時間が増えます）。
