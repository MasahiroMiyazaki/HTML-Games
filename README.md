# HTML-Games

ブラウザだけで遊べる、1ファイル完結のHTMLゲーム集です。インストールやビルドは不要で、HTMLファイルをブラウザで開くだけで動きます。

**遊ぶ（GitHub Pages）**: https://masahiromiyazaki.github.io/HTML-Games/

| ゲーム | ファイル | 説明 |
|---|---|---|
| リバーシ | [reversi.html](reversi.html) | CPU対戦 / 2人プレイ。CPUは4段階 |
| 将棋 | [shogi.html](shogi.html) | CPU対戦 / 2人プレイ。二歩・打ち歩詰め・千日手・入玉宣言に対応 |
| 軍人将棋 | [gunjin-shogi.html](gunjin-shogi.html) | 一人用（CPU対戦）。階級章つきの駒、突入口のある河と総司令部。相手の駒は伏せられ、CPUも正体を知らない状態で指す |
| チェス | [chess.html](chess.html) | CPU対戦 / 2人プレイ。キャスリング・アンパッサン・プロモーションに対応 |

## リバーシ

### 操作方法

| 入力 | 操作 |
|---|---|
| タッチ / マウス | 打ちたいマスをタップ（クリック） |
| キーボード | `←↑→↓` / `WASD` でカーソル移動、`Enter` / `Space` で確定、`R` でリセット |
| ゲームパッド | 十字キー / 左スティックで移動、Aボタンで確定、Startでリセット |

置ける場所には薄い点が表示されます。置けない場所をタップしても何も起きません。

### CPUの強さ

| 段階 | 概要 |
|---|---|
| ノーマル | 位置の重み表に、ひっくり返す枚数を足して選ぶ（1手読み） |
| ハイレベル | アルファベータ法で5手先まで読む。残り9マス以下は終局まで読み切る |
| ヘルモード | 反復深化 + 置換表。最大約1.5秒、中盤10手先まで。残り14マス以下は読み切りを目指す |
| ナイトメア | 同上で最大約5秒、中盤20手先まで。残り20マス以下は読み切りを目指す |

ヘルモード以上は Web Worker で思考するため、考えている間も画面は固まりません。Worker が使えない環境では通常の処理に自動で切り替わります。
思考時間・先読み深さは `reversi.html` 内の `LEVELS`（ヘルモード / ナイトメア）、`SEARCH_DEPTH` / `EXACT_EMPTIES`（ハイレベル）で調整できます。

## 将棋

あなたが先手、CPUが後手です（2人プレイも選べます）。

### 操作方法

| 入力 | 操作 |
|---|---|
| タッチ / マウス | 動かす駒（または持ち駒）をタップし、続けて移動先のマスをタップ。成れる手を指すと「成る／成らない」ボタンが出ます |
| キーボード | `←↑→↓` / `WASD` でカーソル移動、`Enter` / `Space` で確定、`Esc` で取消、`Q` / `E` で持ち駒の選択、`R` でリセット |
| ゲームパッド | 十字キー / 左スティックで移動、Aボタンで確定、Bボタンで取消、LB / RBで持ち駒の選択、Startでリセット、Yボタンで入玉宣言 |

### ルール対応

- 王手の放置・二歩・打ち歩詰めは指せません。詰みは自動で判定します。
- 千日手: 同一局面が4回で引き分け。連続王手の千日手は、王手をかけ続けた側の負けです。
- 入玉宣言: 条件（点数が先手28点／後手27点以上など）を満たすとボタンが出ます。

### CPUの仕組み

駒の価値を中心にした評価（位置の評価は歩1枚分を超えない小さな重み）で、根の手のあと2手読み＋静止探索（取り合いと王手の延長）を行います。最善手と同等の手は乱数で選ぶので、毎回同じ展開にはなりません。1手の思考時間は最大約2.5秒で、超えた場合はそこまでの最善手で指します。
読みの深さは `shogi.html` 内の `DEPTH`、思考時間の上限は `TIME_LIMIT` で調整できます。

## 軍人将棋

一人用（CPU対戦）です。盤は6列×9段（敵陣4段・河1段・自陣4段）、駒は各23枚で、相手の駒は伏せられています。CPUも人間の駒の正体は知らず、動きと勝敗から推測して指します。盤面と勝負表は、中将棋連盟のコラム「[軍人将棋紹介](https://www.chushogi-renmei.com/koramu/koramu-d.htm)」に基づいています。一部にこのゲーム用に決めた設定があります（「このゲーム独自の設定」を参照）。

### 遊び方

1. 最初に自分の駒（下側）を2つ順にタップして入れ替え、「開始」を押します。自陣は23マスに23枚でちょうど埋まるので、空きマスはありません。「配置シャッフル」で配置をやり直せます。
2. 「配置を保存」で、今の配置を1つだけ保存できます。「保存した配置を読込」で呼び出せます。保存先はブラウザの `localStorage` で、端末とブラウザごとに別々です（サーバーには送られません）。
3. 駒をタップし、続けて行き先をタップして動かします。動かせるマスには点が出て、相手の駒がある場所を選ぶと攻撃です。
4. 相手の駒をタップすると、これまでの動きと勝敗から絞り込んだ「正体の候補」が表示されます。駒の中央の朱い点は、その駒がすでに動いたしるしです。
5. 直前に動いたマスは、動いた先が実線、動く前が点線の枠で示されます（赤はCPU、青緑は自分）。CPUの攻撃の結果は、状況表示・戦闘の記録・盤上に出ます。

### 盤

- **河**: 河の段にある2か所の「突入口」からしか渡れません。突入口のマスには駒が止まれます。水のマスには、飛行機でも止まれません。
- **総司令部**: 両陣の最後列中央にある、青い横長のマスです。2マス幅の1マスとして扱い、駒は1枚しか置けません。大将〜少佐だけが敵の総司令部に入れます。
- **駒の見た目**: 将官は黄地に星、佐官は赤地に二本線と星、尉官は赤地に一本線と星の階級章（少=1つ、中=2つ、大=3つ）が付きます。タンク・飛行機・騎兵・工兵・スパイ・地雷・軍旗は、イラストと名前で表します。駒の頭は敵陣を向きます。

### 駒の動き

| 駒 | 動き |
|---|---|
| 大将・中将・少将・大佐・中佐・少佐・大尉・中尉・少尉・スパイ | 縦横に1マス |
| 工兵 | 縦横に1マス。地雷を除去できる |
| 騎兵・タンク | 前に2マスまで、後ろと横に1マスまで（駒は飛び越せない） |
| 飛行機 | 縦はいくらでも、横は隣の1マス。河も、味方・敵の駒も飛び越えられる。地雷を除去できる。味方の駒の上や水の上には止まれない。敵の総司令部には入れない |
| 地雷・軍旗 | 動けない |

飛行機以外の駒は、突入口に入る動きも、突入口から出る動きも1マスずつです（騎兵・タンクが前に2マス進んで突入口を通り抜けることはできません）。飛行機だけが、突入口を通らずに河をこえられます。

### 勝敗

- 勝ち方は2つです。大将〜少佐のどれかで敵の総司令部を占領する、または、相手が大将〜少佐の6枚をすべて失って降伏する。動かせる駒がなくなった側も負けです。大将が倒れても、それだけでは負けません。決着後は全駒が公開されます。
- 駒がぶつかったときは、強い駒が残り、同格は相打ちで、両方とも取り除かれます。勝負の結果は、ゲーム内の「ルールと駒の一覧」の勝負表のとおりです。
- 強さの順は 大将＞中将＞少将＞飛行機＞タンク＞大佐＞中佐＞少佐＞大尉＞中尉＞少尉＞騎兵＞工兵＞スパイ。
- スパイは大将にだけ勝ちます（攻撃側・守備側のどちらでも）。
- 地雷に工兵・飛行機以外が触れると、相打ちになります（地雷も爆発して消えます）。工兵と飛行機は地雷を除去して勝ちます。
- 軍旗は、真後ろにいる自軍の駒と同じ強さで戦います。後ろに駒がなければ、誰にでも負けます。軍旗を取っても、勝敗には関係しません。
- 駒のぶつかり合いがないまま100手が過ぎると、引き分けです。両軍とも大将〜少佐を失った場合も引き分けです。

### 公開ルール

盤の下の「公開ルール」で、いつでも切り替えられます。選んだ設定はブラウザに保存されます。

| 設定 | 内容 |
|---|---|
| 原ルール（初期設定） | ぶつかっても、勝ち負けしか分かりません |
| 攻撃者のみ判明 | 攻撃を仕掛けた駒の正体が、相手に知られます（攻撃した駒が負けて消えた場合も同じ）。知られた自軍の駒には「見」の印が付き、CPUもその正体を前提に動きます |
| 全公開（デバッグ） | 敵の駒をすべて表向きに表示します。CPUの見え方は変わりません |

どの設定でも、CPUの攻撃に勝ったときは撃破した駒の種類が、負けたときは失った自駒の種類が表示されます。負けたときにCPUの駒の正体は明かされません。

### このゲーム独自の設定

ルールページに書かれていない、このゲーム用の設定です。

- 工兵は縦横に1マスずつです（ページでは「縦または横へ何マスでも」）。
- 飛行機以外は、突入口に入る動きも出る動きも1マスずつです。
- 飛行機は縦に駒を飛び越えられます（ある将棋部のローカルルールを参考にしました）。
- 総司令部には、大将〜少佐だけが入れます。
- 駒のぶつかり合いがないまま100手で引き分けです。
- 「攻撃者のみ判明」と「全公開（デバッグ）」の公開ルール、攻撃の結果の表示、配置の保存。

## チェス

あなたが白（下側）、CPUが黒です（2人プレイも選べます）。

- 駒をタップし、続けて行き先をタップします。動かせるマスが表示されます。
- キャスリング、アンパッサン、プロモーション（成る駒を選択）に対応しています。
- チェックメイトで決着し、ステイルメイト・50手ルール・駒不足（キングのみ、またはキング＋ビショップ／ナイト1枚）は引き分けです。三回同形の引き分けには対応していません。
- CPUは3手先まで読みます（強さの段階は1つ）。読みの深さは `chess.html` 内の `DEPTH` で調整できます（大きくすると思考時間が増えます）。
